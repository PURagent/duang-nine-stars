# ดวงชะตา ๙ ดาว

เว็บไซต์: https://puragent.github.io/duang-nine-stars/

โหราศาสตร์ไทยตามหลักสุริยยาตร์ด้วย [thai-astrology](https://github.com/kongesque/thai-astrology) รุ่น **0.3.2** ผสมไพ่ทาโรต์ 78 ใบ ทำงานบน GitHub Pages โดยคงดีไซน์สีน้ำเงิน–ทองและขั้นตอน 4 ขั้นไว้

- เลือกวัน เดือน และปีเกิด พ.ศ. จากเมนู (แสดง ค.ศ. กำกับ) เวลาเกิดเว้นว่างได้
- ปุ่มสำหรับมือถือขนาดอย่างน้อย 56px และเลื่อนไปหัวข้อของขั้นใหม่เมื่อกดถัดไป
- เลือกจังหวัดเกิดได้ครบ 77 จังหวัด หัวข้อ และช่วงเวลา วันนี้ / 7 วัน / 30 วัน ก่อนเปิดไพ่ 3 ใบ
- ใช้ `calculateThaiHoroscope()` สำหรับพื้นดวงสุริยยาตร์ และ `calculateHoroscopeTransits()` สำหรับดาวจร แทนสูตรอาทิตย์/จันทร์แบบประมาณเดิม
- ประมวลผลในเบราว์เซอร์ ไม่ส่งวันเกิดไปยังเซิร์ฟเวอร์ ไม่บันทึกข้อมูลส่วนตัว และไม่ต้องเข้าสู่ระบบ
- ปุ่มแชร์ส่งเฉพาะลิงก์เว็บไซต์ ไม่รวมข้อมูลวันเกิดหรือผลคำทำนาย
- เพื่อความบันเทิงและสะท้อนคิด

## หลักการอ่านผลและข้อจำกัด

- **ทราบเวลาเกิด:** ใช้วัน เวลา และจังหวัดเกิดคำนวณดาวทั้งสิบ ลัคนา ภพทั้ง 12 แบบ whole-sign และทักษา เวลาในฟอร์มคือเวลานาฬิกาท้องถิ่น ณ สถานที่เกิด ไม่ใช่ UTC
- **ไม่ทราบเวลาเกิด:** ยังเล่นได้ โดยใช้ **12:00 น. เป็นเวลาอ้างอิง** และระบุไว้ในผลลัพธ์ ไม่แสดงลัคนา ภพ ทักษา หรือตนุลัคน์/ตนุเศษจากเวลาสมมติ ตำแหน่งดาว โดยเฉพาะจันทร์ อาจต่างจากเวลาเกิดจริง
- **สถานที่:** จังหวัดใช้พิกัดเมืองศูนย์กลางที่ไลบรารีกำหนด ไม่ใช่พิกัดโรงพยาบาลหรือสถานที่เกิดจริง ส่งชื่อจังหวัดเต็มเข้าไลบรารีเพื่อให้เลือกจุดอ้างอิงอาทิตย์ขึ้นและเขตเวลาอัตโนมัติ ไม่ใช้รหัส `TH-xx` ซึ่งยังไม่รองรับในรุ่น 0.3.2
- **ดาวจร:** จับเวลาจากนาฬิกาอุปกรณ์เมื่อเริ่มอ่าน ใช้เขตเวลา `Asia/Bangkok` และจังหวัดเกิดเป็นจุดอ้างอิง ช่วง 7/30 วันคำนวณวันละหนึ่งจุด ณ เวลาไทยเดียวกัน รวมวันเริ่มต้นเป็นวันแรก (offset 0–6 / 0–29) จึงไม่ใช่เวลาย้ายราศีที่ละเอียดถึงนาที และการเปลี่ยนราศีระหว่างจุดตัวอย่างอาจไม่ปรากฏ
- **ปฏิทิน:** วันจันทรคติไทยรองรับช่วง ค.ศ. 1582–2076 และอาจต่างจากปฏิทินที่เผยแพร่ ใช้ `thaiLunarDate` ไม่ใช่ค่า `lunarDay` ที่นับจากมุมห่างอาทิตย์–จันทร์
- **ไพ่และคำอ่าน:** สำรับ 78 ใบและข้อความเพื่อสะท้อนคิดเป็นส่วนของเว็บ ไม่ใช่คำทำนายที่ไลบรารี `thai-astrology` สร้างให้ การใช้สูตรสุริยยาตร์ไม่ได้ยืนยันความแม่นยำในการทำนายอนาคตทางวิทยาศาสตร์ และไม่ใช่คำแนะนำด้านสุขภาพหรือการเงิน

### หมายเหตุสำหรับผู้ดูแล

ตรึง dependency เป็น `thai-astrology@0.3.2` พร้อม lockfile เพื่อให้ผลคำนวณทำซ้ำได้ เอกสารบน branch `main` ของ upstream อาจกล่าวถึง API ที่ใหม่กว่ารุ่น npm นี้ จึงควรตรวจแพ็กเกจที่ติดตั้งจริงก่อนอัปเกรด

รุ่น 0.3.2 มีการปรับสมผุสมฤตยูเฉพาะชุดข้อมูล **29 กุมภาพันธ์ ค.ศ. 1904 เวลา 03:47 น. จังหวัดแม่ฮ่องสอน** ในโค้ด upstream เว็บจึงไม่แสดงผลสำหรับชุดข้อมูลนี้และแจ้งว่าไม่รองรับ เพื่อไม่ให้ผลเฉพาะกรณีนี้ถูกนำเสนอเหมือนการคำนวณทั่วไป ไม่มีการแก้สูตรภายใน dependency

## แก้ไขและสร้างเว็บ

ใช้ Node.js 22 ขึ้นไป:

```sh
npm ci
npm test
npm run build
```

ชุดทดสอบใช้ Node.js test runner ซอร์สหน้าจออยู่ใน `src/App.tsx` และ `src/horoscope.css` ส่วนการเชื่อมไลบรารีอยู่ใน `src/astrology.js`

มีสคริปต์ทดสอบเบราว์เซอร์เพิ่มเติมที่ `test/browser-smoke.mjs` สำหรับเครื่องที่ติดตั้ง Playwright และ Chromium ไว้แล้ว ใช้ `node test/browser-smoke.mjs` เพื่อตรวจ build ในเครื่อง หรือกำหนด `SITE_URL` เพื่อตรวจเว็บที่เผยแพร่ สคริปต์นี้แยกจาก `npm test` และต้องมีสภาพแวดล้อมที่อนุญาตให้เปิดเบราว์เซอร์ได้

`docs/` คือไฟล์พร้อมเผยแพร่ที่รวม React และตัวคำนวณสุริยยาตร์ไว้แล้ว ไม่ต้องใช้ CDN หรือ API ภายนอกในการคำนวณขณะเปิดเว็บ `build.mjs` ใส่ hash ของ JavaScript/CSS ใน URL ของไฟล์เพื่อให้เบราว์เซอร์โหลดรุ่นที่อัปเดต

หลังแก้ไขให้ build แล้ว commit ทั้งซอร์สและ `docs/` เข้า `main` GitHub Pages เผยแพร่จาก branch `main` โฟลเดอร์ `/docs`
