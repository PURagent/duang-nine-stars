# ดวงชะตา ๙ ดาว

เว็บไซต์: https://puragent.github.io/duang-nine-stars/

โหราศาสตร์ไทยแบบประมาณและไพ่ทาโรต์ 78 ใบ ย้ายจากเว็บไซต์เดิมมาทำงานบน GitHub Pages โดยคงดีไซน์สีน้ำเงิน–ทองและขั้นตอน 4 ขั้นไว้

- กรอกวันเกิด เลือกหัวข้อและช่วงเวลา เปิดไพ่ 3 ใบ แล้วอ่านคำทำนาย
- ประมวลผลในเบราว์เซอร์ ไม่ส่งวันเกิดไปยังเซิร์ฟเวอร์ ไม่บันทึกข้อมูลส่วนตัว และไม่ต้องเข้าสู่ระบบ
- ปุ่มแชร์ส่งเฉพาะลิงก์เว็บไซต์ ไม่รวมข้อมูลวันเกิดหรือผลคำทำนาย
- ตำแหน่งอาทิตย์/จันทร์เป็นสูตรประมาณ ยังไม่ใช่สุริยยาตร์หรือลัคนาฉบับสมบูรณ์ เวลาและจังหวัดเกิดยังไม่ใช้ในสูตร
- เพื่อความบันเทิงและสะท้อนคิด

## แก้ไขและสร้างเว็บ

ใช้ Node.js 22 ขึ้นไป:

```sh
npm ci
npm run build
```

ซอร์สหลักอยู่ใน `src/App.tsx` และ `src/horoscope.css` ส่วน `docs/` คือไฟล์พร้อมเผยแพร่ที่รวม React ไว้แล้ว ไม่ต้องใช้ CDN ภายนอกขณะเปิดเว็บ

หลังแก้ไขให้ build แล้ว commit ทั้งซอร์สและ `docs/` เข้า `main` GitHub Pages เผยแพร่จาก branch `main` โฟลเดอร์ `/docs`

ไฟล์ SVG เป็นภาพประกอบเดิมของโปรเจกต์ ข้อความลิขสิทธิ์ไลบรารีที่รวมมาจะอยู่ใน `docs/assets/app.js.LEGAL.txt`
